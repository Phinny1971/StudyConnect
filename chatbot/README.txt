MAGI AI - Complete Chatbot Package

FEATURES
- AI study abroad assistant
- File uploads
- Chat history
- Escalation support
- Streaming AI responses

SETUP
1. Import database_schema.sql
2. Configure:
   - config/openai_config.php
   - includes/db.php
3. Enable PHP extensions:
   - curl
   - mysqli

RECOMMENDED PRODUCTION IMPROVEMENTS
- Use environment variables for API keys
- Add CSRF protection
- Add rate limiting
- Add HTTPS
- Secure uploads folder
- Add admin logging
